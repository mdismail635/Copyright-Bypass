## 📱 Android Termux এ ১ ক্লিকে ইনস্টল ও চালানোর নিয়ম

আপনার অ্যান্ড্রয়েড মোবাইলে **Termux** অ্যাপটি ওপেন করে নিচের কমান্ডগুলো রান করুন:

```bash
# ১. গিট ক্লোন করুন
git clone https://github.com/mdismail635/Copyright-Bypass.git

# ২. ফোল্ডারে প্রবেশ করুন
cd Copyright-Bypass

# ৩. অটো সেটআপ স্ক্রিপ্ট রান করুন (শুধু প্রথমবার)
bash termux_setup.sh

# ৪. অ্যাপ চালু করুন
bash termux_start.sh
```

> 💡 **নোট:** অ্যাপটি চালু হওয়ার সাথে সাথে আপনার ফোনের ক্রোম ব্রাউজারে `http://localhost:5000` স্বয়ংক্রিয়ভাবে খুলে যাবে। আপনি মোবাইল থেকেই ভিডিও সিলেক্ট করবেন এবং এডিট শেষ হলে ভিডিও সরাসরি আপনার ফোনের **Download** ফোল্ডারে সেভ হয়ে যাবে।
